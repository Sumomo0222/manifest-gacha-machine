# 🔮 祝福显化扭蛋机

一个「梦幻霓虹玩具店」风格的互动祝福扭蛋机静态网页：投入一枚心愿币，转动实体旋钮，胶囊翻滚掉落，打开后弹出一张专属显化祝福卡。

> 「显化」是提供情绪价值的创意互动，不承诺任何现实结果。

## ✨ 玩法与动效

1. **投币**：点击投币口，金色「wish」心愿币飞入币槽，机器轻震。
2. **转旋钮**：旋钮点亮后点击，旋转 540°，玻璃罩内胶囊翻滚。
3. **胶囊掉落**：一颗随机配色的胶囊从玻璃罩滚出、穿过出蛋口挡板、弹落托盘。
4. **开胶囊**：点击托盘上的胶囊，上下壳弹开，祝福卡弹出，附赠 emoji 彩带。
5. **祝福卡**：随机出现一条显化祝福（不会与上次重复），包含：
   - 祝福名称
   - 显化提示
   - 今日小行动
   - 分享短句
6. **按钮**：`📋 复制祝福`（一键复制整卡文案）/ `🎰 再抽一次`（重置机器重新开始）。

另有：WebAudio 合成音效（投币、棘轮咔哒、掉落、开盒，右上角可静音）、星空闪烁背景、霓虹招牌闪烁动画、`prefers-reduced-motion` 降级。桌面与手机（触屏）均可完整操作。

## 📁 目录结构

```
manifest-gacha-machine/
├── README.md          # 本文件
└── dist/              # 最终页面（发布用，纯静态）
    ├── index.html
    ├── style.css
    └── app.js
```

无构建步骤、无框架、无外部资源请求（含字体），全部本地相对路径。

## 🚀 本地预览

方式 A：直接用浏览器打开

```
open dist/index.html        # macOS
```

方式 B：起一个本地静态服务器

```
cd dist
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 🎨 如何修改

| 想改什么 | 位置 |
|---|---|
| 祝福内容（增删改） | `dist/app.js` 顶部 `BLESSINGS` 数组，每条含 `name / tip / act / share` 四个字段 |
| 胶囊配色 | `dist/app.js` 的 `CAP_PALETTE`；罩内胶囊颜色在 `index.html` 各 `.capsule` 的 `--cap` |
| 霓虹主题色 / 布局尺寸 | `dist/style.css`（机器整体缩放：`.machine` 的 `font-size: clamp(...)`，全部内部尺寸用 `em` 随动） |
| 页面文案 / 结构 | `dist/index.html` |

## ☁️ 如何部署（静态 CDN）

本项目即用 Vercel 发布：

```bash
npm i -g vercel
vercel login
vercel deploy dist --prod --yes
```

其他静态托管任选其一：

- **GitHub Pages**：把 `dist/` 内容放进仓库根目录（或 `docs/` 目录）并推送；Pages 分支模式只支持 `/` 或 `/docs` 两种源路径。
- **Cloudflare Pages / Netlify**：部署目录指向 `dist/` 即可。
- **任意对象存储 + CDN**（OSS、COS、七牛等）：把 `dist/` 三个文件上传为静态站点根文件。
