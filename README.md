# 🎁 显化扭蛋机 · Manifestation Gacha

一台会抽出美好祝福的显化扭蛋机。投一枚「心愿币」,转动旋钮,看一枚祝福胶囊咕噜噜滚落——打开它,收下今天属于你的一句好运。

> 「显化」在这里是一种创意互动与情绪价值表达:它不预测未来、不承诺任何现实结果,只负责让你心里亮一下 ✨

## ✨ 它是什么

- 纯 HTML / CSS / JavaScript 手写的静态网页,零依赖、零框架,打开即玩。
- 一台纯 CSS 手绘的霓虹风扭蛋机:玻璃罩里 6 种祝福胶囊轻轻漂浮,星光、粒子与星云在背景里流动。
- 18 种祝福结果,随机抽取,每次都不一样;机器屏幕实时播报当前状态。
- Web Audio 合成音效(投币、棘轮、掉落、开盖),可一键静音。

## 🕹 交互一览

| 交互 | 玩法 |
| --- | --- |
| 🪙 投入心愿币 | 点击「投入心愿币」,金币翻转落入投币口,进入待扭状态 |
| 🌀 转动扭蛋 | 点击旋钮(或「转动扭蛋」按钮),旋钮旋转、机器震动、罩内胶囊翻滚 |
| 📦 打开胶囊 | 胶囊从出货口掉到托盘后,点击它:壳盖弹开、光效迸发,祝福卡片登场 |
| 🎲 再抽一次 | 在卡片上一键回炉,自动投币,直接再扭一发 |
| 📋 复制祝福 | 把本次祝福文案复制到剪贴板,方便分享给朋友 |
| 🔊 音效开关 | 页脚随时静音 / 开启,偏好会被记住 |

彩蛋:

- 抽取进度「已显化 n / 18」保存在浏览器 `localStorage`,集齐一种胶囊类型会在图例上打勾;
- 旋钮与胶囊都是可聚焦按钮,支持键盘 Enter / Space 操作;
- 系统开启「减弱动态效果」时,动效会自动收敛。

## 🖥 本地打开

无需构建、无需本地服务器:

1. 下载或克隆本目录;
2. 直接双击打开 `index.html`(Chrome / Edge / Safari / Firefox 均可)。

`dist/` 内是同一套文件的部署副本,内容一致,部署时用哪个都行。

## 🚀 部署

任意静态托管都能用,把 `dist/`(或根目录)整体上传即可。所有资源均为相对路径,子路径部署(如 `username.github.io/repo/`)无需任何改动:

- **GitHub Pages**:建仓推送后,Settings → Pages → 选择 main 分支 `/` 根目录;
- **Vercel**:`vercel deploy <目录> --prod`;
- **Netlify**:把 `dist/` 拖进 Netlify Drop;
- **Cloudflare Pages**:创建项目,构建命令留空,输出目录填 `dist`。
